# Statistical analysis plan

The primary estimand is design-weighted nominal Krippendorff alpha across five independent classifications of the frozen main sample. Primary intervals use the stratified sampling design and finite-population correction. Delete-one jackknife intervals provide a sensitivity analysis. The registered critical value is 2.25. A result is classified against the 0.667 and 0.80 thresholds only when the corresponding interval and half-width rules are satisfied.

The batching pilot compares paired classifications under six registered regimes. The decision margin is 0.10. The pilot passes only when every upper confidence limit is below that margin. Any lower confidence limit at or above the margin establishes inferiority. Other outcomes remain inconclusive and cannot authorize the main phase.
